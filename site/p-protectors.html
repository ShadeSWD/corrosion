Расчёт протекторной защиты

Расчёт состоит из двух независимых условий, и выполнены должны быть оба. Первое — энергетическое: протекторов должно хватить по массе на весь назначенный срок службы. Второе — токовое: они должны быть способны отдать нужный ток здесь и сейчас, иначе потенциал корпуса не сместится в защитный коридор, сколько бы металла ни висело на обшивке. Число протекторов — большее из двух.

Коротко

  • Ток защиты \(I = i\,S\) — плотность защитного тока умножить на площадь; \(i\) назначают по состоянию покрытия и району плавания.
  • Масса сплава \(M = I\,T\,8760/(q\,k_{\text{и}})\), где \(q\) — фактическая токоотдача сплава, А·ч/кг.
  • Токоотдача одного протектора \(I_1 = \Delta E/R_{\text{а}}\), где \(R_{\text{а}} = 0{,}315\,\rho/\sqrt{A_{\text{а}}}\) — сопротивление растеканию плоского прилегающего анода.
  • Итог — \(n = \max(n_m,\ n_i)\) с округлением вверх.

Исходные данные

Схема размещения: прямоугольник в масштабе защищаемой площади, точки — протекторы, разнесённые равномерно. Реальная расстановка учитывает районы повышенного тока (перо руля, кронштейны, район винта) и зоны действия соседних анодов.

Шаг 1. Площадь защищаемой поверхности

Если площадь не снята с чертежа, для днища вместе с поясом переменных ватерлиний пользуются оценочной формулой книги инспектора; коэффициент \(P\) учитывает полноту обводов.

$$A = (2d + B)\,L_{pp}\,P$$

Шаг 2. Ток защиты

Плотность защитного тока — главное проектное допущение всего расчёта. Она отражает не «сколько нужно металлу», а сколько тока придётся подать на квадратный метр с учётом ожидаемого разрушения покрытия. Для сравнения: собственный ток коррозии голой стали при 0,12 мм/год составляет около 103 мА/м² (см. главу 2).

$$I = \frac{i\,S}{1000}$$

Шаг 3. Требуемая масса протекторного сплава

Закон Фарадея, записанный через фактическую токоотдачу сплава \(q\) [А·ч/кг]: сколько ампер-часов способен отдать килограмм. Коэффициент использования \(k_{\text{и}}\) учитывает, что к концу срока протектор теряет форму и часть металла отваливается, не отработав.

Требуемый заряд: $$Q = I\,T\cdot 8760$$
$$M = \frac{I\,T\cdot 8760}{q\,k_{\text{и}}}$$
Число протекторов по массе: $$n_m = \left\lceil \frac{M}{m_1} \right\rceil$$

Шаг 4. Токоотдача одного протектора

Ток, который реально отдаёт протектор, определяется движущим напряжением и сопротивлением растеканию тока с его поверхности в воду. Для плоского анода, прилегающего к корпусу, пользуются формулой Мак-Коя, где \(A_{\text{а}}\) — площадь открытой рабочей поверхности:

Движущее напряжение: $$\Delta E = \varepsilon_{\text{защ}} - \varepsilon_{\text{а}}$$
Сопротивление растеканию: $$R_{\text{а}} = \frac{0{,}315\,\rho}{\sqrt{A_{\text{а}}}}$$
$$I_1 = \frac{\Delta E}{R_{\text{а}}}$$
Число протекторов по току: $$n_i = \left\lceil \frac{I}{I_1} \right\rceil$$
Видно, зачем в справочниках указывают рабочий потенциал сплава, а не только токоотдачу. Магниевый МП1 при −1,21 В даёт движущее напряжение почти втрое больше алюминиевого АП4Н — и потому годится для пресной и солоноватой воды, где велико \(\rho\). Но на окрашенном стальном корпусе он же загоняет потенциал в область перезащиты (отрицательнее −0,85 В), где начинается отслаивание покрытия и наводороживание, — поэтому магниевые протекторы ставят через регулировочные сопротивления.

Шаг 5. Итог и проверки

$$n = \max(n_m,\ n_i)$$
Площадь, приходящаяся на один протектор: $$S_1 = \frac{S}{n}$$
Суммарная установленная масса: $$M_{\text{уст}} = n\,m_1$$
Фактический запас по току: $$k_I = \frac{n\,I_1}{I}$$
